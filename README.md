# axo-landing (forwarding only)

The axo website lives at **[axolab.space](https://axolab.space)**. Its source is **[arinaesp/axolab](https://github.com/arinaesp/axolab)**.

This repository keeps the site's old address working. Anything under
`arinaesp.github.io/axo-landing/` forwards to the same page on axolab.space,
because older posts and messages still link there.

There is nothing else here, and nothing to contribute: please open issues in [arinaesp/axolab](https://github.com/arinaesp/axolab).
